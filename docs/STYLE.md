# DaZ-Alex – Look and feel (dyslexia-friendly)

- **Notebook page:** the page is butter-yellow squared paper (`--paper` #fff8d1, faint grid, red margin line) on a cream-white desk (`--desk` #fcf9f1), like the yellow paper many dyslexic pupils write on. Cards and exercises sit on solid light surfaces, so no text lies directly on the grid.
- **Font:** Comic Neue (self-hosted, open licence): a slimmer cousin of Comic Sans; Comic Sans MS is only the fallback. No italics, no justified text.
- **Spacing:** line height 1.75, slightly wider letters and words. The button "Weiter Abstand" widens them further. Text size A− / A+.
- **Colour teaches, but is never alone:** der = blue, die = red, das = green, Plural = orange. Every coloured word also has an underline or label. All colours pass the axe contrast check (`npm run a11y`).
- **One task at a time**, short lines, big tap targets, calm motion (off with `prefers-reduced-motion`).
- **No read-aloud, no sounds.**
